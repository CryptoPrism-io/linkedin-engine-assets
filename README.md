# linkedin-engine-assets

Public image hosting for the `linkedin-engine` Buffer post pipeline. Buffer's API requires
posted media to be a publicly reachable URL (no upload endpoint) — this repo holds only the
infographic PNGs, no post text, credentials, or other business content.

Images: `infographics/slot-NN.png`, referenced from Buffer posts via
`https://raw.githubusercontent.com/CryptoPrism-io/linkedin-engine-assets/main/infographics/slot-NN.png`.
